# PO_test

Et lille testprojekt.

## hej.py

Scriptet `hej.py` printer teksten `Hej fra PO_test` i terminalen.

### Krav

- Python 3 installeret

### Sådan kører du den

Stå i projektets rodmappe og kør:

```bash
python3 hej.py
```

På Windows kan du bruge:

```bash
python hej.py
```

Forventet output:

```
Hej fra PO_test
```
